Before any active workflow

  • Write down the scope: hosts, ranges, ports and time window.
  • Confirm that you own the systems or have explicit permission from the responsible owner.
  • Check whether the environment has IDS/IPS, rate limits or change freezes.
  • Prefer the smallest probe that answers your question.
  • Store results somewhere appropriate for potentially sensitive data.

See Security and responsible use for repository trust, privilege handling, data sensitivity and rate limits.
