What the installer does

A calm front door to a serious toolkit.

The installer handles the boring parts — package manager detection, privilege boundaries, retries, logs and verification — so you can spend your time understanding the network.

Read the documentation →

One command, nine groups

Install every group with --all, pick individual groups with --tool, or use the interactive terminal menu.

Built for many systems

Detects apt, dnf, yum, pacman, zypper, apk or Homebrew and uses the right package names for each one.

See before you change

--dry-run prints the exact package-manager commands without touching the system. --check audits what is already present.

Resilient by design

Packages install one at a time, so a single unavailable dependency does not abort the whole run. Failures are logged and reported.

Signed APT repository

Debian-based systems can install and update a signed package, with the repository keyring fetched from this site.

Transparent status and logs

Every run prints a per-command status table, writes installer output to a temporary log, and exits non-zero when tools are missing.

Supported tools

Thirteen tools, thoughtfully grouped.

The installer ships external, well-established utilities. Each tool has its own documentation page covering purpose, installer handling, commands, output and troubleshooting.

Installation

Three commands, one signed repository.

On Debian, Ubuntu, Kali and Linux Mint, the recommended route is the signed APT repository. It keeps the installer updated like any other package.

  1. Trust the repository key

    Fetch eergn-archive-keyring.gpg and store it under /usr/share/keyrings.

  2. Add the source

    Point APT at this GitHub Pages repository, restricted to the downloaded key.

  3. Update and install

    Refresh metadata, install eergn-recon-installer, then run it with sudo.

Use these tools only on systems and networks you own or have explicit permission to assess. The installer does not grant authorization.
Signed APT setup Recommended 
# 1. Add the repository signing key
curl -fsSL https://eergn.github.io/eergn-network-recon-installer/eergn-archive-keyring.gpg \
  | sudo tee /usr/share/keyrings/eergn-archive-keyring.gpg >/dev/null

# 2. Add the signed repository
echo "deb [signed-by=/usr/share/keyrings/eergn-archive-keyring.gpg] \
https://eergn.github.io/eergn-network-recon-installer ./" \
  | sudo tee /etc/apt/sources.list.d/eergn.list

# 3. Refresh metadata and install
sudo apt update
sudo apt install eergn-recon-installer

# 4. Launch the interactive installer
sudo eergn-recon-installer
