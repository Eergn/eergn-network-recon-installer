What this project is

Eergn Network Recon Installer is a single-file Bash CLI. It detects the host's package manager and installs a curated set of network discovery and diagnostic utilities. It does not implement scanning itself, does not run scans for you, and does not grant permission to test a system.

The installer supports nine tool groups:

Verified baseline

This documentation was written against installer 1.0.0 and the exact source in the repository. The APT package metadata in docs/Packages reports version 1.0.0 and dependency bash. Upstream tools change over time; check their own manuals for version-specific behavior.

How to read the examples

Examples use private, documentation-reserved address ranges such as 192.168.1.0/24 and hostnames such as lab.example.internal. Replace them with systems you own or have explicit written permission to assess. Active tools send traffic to the target; their examples are not passive observations.

Commands are shown for the current user. Where a tool requires elevated privileges, the example says so explicitly. Avoid running entire workflows as root when a single tool needs raw socket access.

Verified versus unverified

The repository has no automated test suite. Claims marked as verified come from reading the installer source, running the installer's non-destructive modes, inspecting the shipped package metadata, or reading installed help output and official upstream documentation. Anything version-dependent or environment-dependent is described as such. Where a behavior could not be confirmed from those sources, this documentation says so rather than guessing.

Authorized use only

Network reconnaissance can look like scanning or intrusion to monitoring systems. Use these tools only on networks and systems you own or have documented permission to assess, and follow the rules of engagement for the environment.
