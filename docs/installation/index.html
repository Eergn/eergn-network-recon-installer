Installation

The installer is distributed as a signed APT package for Debian-based systems, a downloadable .deb, a standalone Bash script for every supported platform, and the repository itself.

Before you install

These tools are for networks and systems you own or are explicitly authorized to assess. Installing them does not create authorization. On Linux, the installer needs root or sudo for package installation. On macOS it uses Homebrew and must not be run as root.

Prerequisites

  • Linux: Bash 3.2 or newer, a supported package manager, and root or sudo.
  • macOS: Bash 3.2 or newer and Homebrew. Run the installer without sudo.
  • An internet connection to download packages and, for testssl.sh, possibly Git and the upstream repository.
  • For the APT route: Debian, Ubuntu, Kali, Linux Mint or a compatible Debian-based distribution with apt and network access to GitHub Pages.

Supported package managers in the source are apt, dnf, yum, pacman, zypper, apk and Homebrew. The README lists Debian, Ubuntu, Kali, Mint, Fedora, RHEL, Rocky, Alma, Arch, Manjaro, openSUSE, Alpine and macOS as the intended platforms.

Option A — signed APT repository (recommended for Debian-based systems)

This is the method published on the project's GitHub Pages site. It installs the package and lets future versions arrive through normal APT upgrades.

1. Add the signing key

curl -fsSL https://eergn.github.io/eergn-network-recon-installer/eergn-archive-keyring.gpg \
  | sudo tee /usr/share/keyrings/eergn-archive-keyring.gpg >/dev/null

curl -fsSL fails on HTTP errors and suppresses progress output. The key is written to the system keyring directory, not to the legacy trusted-key list. The published key is an Ed25519 signing key with fingerprint:

900D437EB8F512053DA25632AEF17B55E71A8350

2. Add the repository

echo "deb [signed-by=/usr/share/keyrings/eergn-archive-keyring.gpg] https://eergn.github.io/eergn-network-recon-installer ./" \
  | sudo tee /etc/apt/sources.list.d/eergn.list

The signed-by option restricts this repository to the downloaded key. The suite is ./ because the repository is a flat package directory served from the project site. Do not change it to a distribution codename unless the repository is rebuilt that way.

3. Refresh and install

sudo apt update
sudo apt install eergn-recon-installer

The package name is eergn-recon-installer. It is architecture all, depends on bash, and installs the command at /usr/bin/eergn-recon-installer plus a man page.

4. Verify

eergn-recon-installer --version
eergn-recon-installer --list
dpkg -s eergn-recon-installer
man eergn-recon-installer

--version prints the installer name, version and author. --list prints the nine group IDs. dpkg -s confirms the package is installed. The man page documents the same options that appear in --help.

Option B — install a .deb file

Download the package from the latest GitHub release, or use the copy served in this repository, then install it locally:

sudo apt install ./eergn-recon-installer_1.0.0_all.deb
sudo eergn-recon-installer

A local path beginning with ./ tells APT to install the file rather than looking up a repository package. Remove it later with sudo apt remove eergn-recon-installer.

Option C — download the standalone script

This route works on every supported system, including distributions without the APT package.

curl -LO https://github.com/Eergn/eergn-network-recon-installer/releases/latest/download/eergn-recon-installer.sh
chmod +x eergn-recon-installer.sh
sudo ./eergn-recon-installer.sh

On macOS, omit sudo:

chmod +x eergn-recon-installer.sh
./eergn-recon-installer.sh
Release asset availability

The README documents this download URL. This documentation could not verify that a GitHub release asset named eergn-recon-installer.sh is attached to the latest release from the repository contents alone. If the URL returns 404, use the repository clone method or the APT package.

Option D — clone the repository

git clone https://github.com/Eergn/eergn-network-recon-installer.git
cd eergn-network-recon-installer
chmod +x eergn-recon-installer.sh
sudo ./eergn-recon-installer.sh

Use this route if you want to inspect the source before running it or contribute changes. The script is self-contained; it does not source files from the repository at runtime.

Install tools, not just the installer

Installing the package or script only places the installer. To install the external tools, run it with sudo:

# Interactive menu
sudo eergn-recon-installer

# Install every group without prompts
sudo eergn-recon-installer --all -y

# Install selected groups
sudo eergn-recon-installer -t nmap -t dns -t tls

# Preview commands without making changes
eergn-recon-installer --all --dry-run

See the command reference for every flag and the tool catalog for group membership.

Updating

Installer installed from APT

sudo apt update
sudo apt upgrade

Standalone script

Download the newer script again and replace your local copy. The script has no self-update command.

External tools

Use the system package manager (for example sudo apt upgrade or brew upgrade). The installer does not provide an --update mode, and re-running it skips groups whose commands already exist unless you pass --force.

Uninstalling

# Remove the installer package
sudo apt remove eergn-recon-installer

# Remove the APT source and key if you no longer want updates
sudo rm /etc/apt/sources.list.d/eergn.list
sudo rm /usr/share/keyrings/eergn-archive-keyring.gpg
sudo apt update

Removing the installer does not automatically remove the external tools it installed. Remove those explicitly with your package manager if desired. The testssl.sh Git fallback may live in /opt/testssl.sh with a symlink at /usr/local/bin/testssl.sh; the installer does not remove it.

Trust the key you fetch

Fetching a key over HTTPS and trusting it in the same step protects the transport, not the publisher. Compare the fingerprint with the one published in the repository before adding a third-party key. See Security.

Troubleshooting installation

If APT reports a missing package, a signature error, a keyring error or an unreachable repository, see Troubleshooting installation and the general troubleshooting reference.
